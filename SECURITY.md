# Security

Do not report credentials, private screenshots, or exploitable details in public issues. Use GitHub private vulnerability reporting for this repository when available; otherwise contact the maintainer through their GitHub profile to arrange a private report.

AI keys are limited to one project and selected permissions. An AI with task-write permission can still make unwanted changes inside that project; human review and backups remain important. Revoke a credential in Settings → AI access when it is no longer needed.

Use HTTPS for shared installations and choose strong passwords and random installation/session secrets. Short passwords are supported for local use but should not be used on a publicly reachable server. No MFA or email password recovery is included. Source publication does not expose or host your installation.

See docs/MAINTAINER.md and docs/LIMITATIONS.md for current authentication, storage and deployment constraints.
